# Glossary

Use these words in code, UI copy and docs. If a concept needs a new word,
add it here first. The model behind the terms is described in
[docs/product/domain-model.md](docs/product/domain-model.md).

## People and structure

| Term                    | Meaning                                                                                                                                                                                                          | Not to be confused with                    |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| **Tenant**              | One firm, mapped to one Entra ID tenant. Every row belongs to exactly one tenant.                                                                                                                                | Business function                          |
| **Person**              | Someone in the tenant directory, mirrored from Entra ID.                                                                                                                                                         | "User" (use only in auth code)             |
| **Business function**   | A tenant taxonomy entry (Advisory, Client Service, …). It is a facet of a person, not a container.                                                                                                               | Team                                       |
| **Reporting line**      | An effective-dated _manager → report_ edge synced from the directory.                                                                                                                                            | Coaching engagement                        |
| **Leader**              | Anyone on the manager end of an active reporting line. Derived, never stored.                                                                                                                                    | Coach                                      |
| **Team**                | A leader plus their current direct reports. Derived, never stored.                                                                                                                                               | Cohort                                     |
| **Coach**               | A person holding the `coach` role grant (from the Entra app role).                                                                                                                                               | Leader                                     |
| **Coaching engagement** | A _coach ↔ coachee_ relationship in the mesh, proposed then accepted. Carries no reporting authority.                                                                                                            | Reporting line                             |
| **Coachee**             | Anyone with a development plan or an engagement. Everyone can be one.                                                                                                                                            | Advisor (a job title)                      |
| **Role grant**          | A dated capability from an Entra app role: `coach`, `tenant_admin`, `compliance_reviewer` or `program_owner`.                                                                                                    | Leader or coachee, which are relationships |
| **Program owner**       | A person holding the `program_owner` grant. Runs the program: sees the adoption view and maintains the credit rules, the skill catalog and the activity templates (ADR 0021, ADR 0023). Sees nothing per person. | Tenant admin                               |
| **Job family**          | A tenant taxonomy of jobs from the HR feed, such as _Financial advisor_. Pinned on credit through the position; expectations are deferred (ADR 0017).                                                            | Business function, Title                   |
| **Position**            | An effective-dated record of a person's job family, title and business function. A credit pins the subject's position on the interaction date (null when the directory does not know it).                        | Person, which is not dated                 |

## Development

| Term                  | Meaning                                                                                                                                                                                                                                                                                 | Not to be confused with                             |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| **Skill**             | A named capability that matters to the business, e.g. _Client discovery_.                                                                                                                                                                                                               | Badge                                               |
| **Skill version**     | An immutable published definition: four levels, each with observable indicators.                                                                                                                                                                                                        |                                                     |
| **Level**             | One step on a skill's ladder: 1 Learning, 2 Doing with support, 3 Doing independently, 4 Teaching others.                                                                                                                                                                               |                                                     |
| **Indicator**         | An observable behavior at a level. Optional for the observer to tick. It carries a `lineage_key` that stays stable across versions.                                                                                                                                                     | Trait                                               |
| **Activity template** | A reusable piece of real work, e.g. _Discovery meeting with a new client_, with its skills (each primary or secondary, optionally with a value) and a tip for observers. Program owners maintain them. Adding work from a template copies its roles and values onto the activity once.  | Activity                                            |
| **Development plan**  | A coachee's plan for a period: one to three focus skills, each with a **plan target** (a target level), plus the activities that will develop them.                                                                                                                                     |                                                     |
| **Plan target**       | The level a focus skill is worked toward in one plan. Judged by people in the closing review, never by a badge; level 4 is a valid target although it has no badge.                                                                                                                     | Badge                                               |
| **Closing review**    | What became of each focus skill when a plan ends: `achieved`, `partly`, `carried_over` or `not_pursued`, plus a closing summary. Recorded by the owner, confirmed (and then fixed) by the coach, or the leader when there is no coach. Never computed from badges; never writes credit. | Badge, lifecycle                                    |
| **Activity**          | One item of planned real work, with its skills (each **primary** or **secondary**) and an **observation commitment** (who will see it, and how). It is either `planned` or `ad_hoc`.                                                                                                    | Interaction                                         |
| **Interaction**       | One dated occurrence of doing the work.                                                                                                                                                                                                                                                 | Observation                                         |
| **Client reference**  | An opaque CRM ID. Never a name.                                                                                                                                                                                                                                                         |                                                     |
| **Evidence**          | The coachee's reflection on an interaction, screened for privacy.                                                                                                                                                                                                                       | Observation                                         |
| **Try next time**     | The latest signed observation's "What next" (signed or under review), shown first on Home and on the coachee's plan, to readers who may see narratives. Not stored separately.                                                                                                          | Activity                                            |
| **Quick capture**     | The one-screen "I saw this": an observer records who, when, mode, skills, level and comment, and signs or saves to finish later.                                                                                                                                                        | Logging an interaction, which is the coachee\'s act |

## Recognition

| Term                                  | Meaning                                                                                                                                                                                                                                                                  | Not to be confused with                     |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------- |
| **Observation**                       | An eligible observer's account of an interaction: a level per skill plus one specific comment. It counts only once **signed**.                                                                                                                                           | Confirmation, which is the `SIGN` step      |
| **Observer**                          | The person writing the observation: the subject's direct leader, an engaged coach, or a designated observer, as of the interaction date.                                                                                                                                 | Witness                                     |
| **Designation / designated observer** | A colleague named by the subject's leader or engaged coach to observe them for a window of at most 90 days. Audited and visible to the subject (ADR 0020).                                                                                                               | Delegation of any other right               |
| **Basis**                             | Why the observer was eligible (`leader`, `coach` or `designated`), pointing at the exact edge or designation row.                                                                                                                                                        |                                             |
| **Mode**                              | How the observer knows. `saw_it` (was there), `reviewed_work` (recording or work product), or `discussed` (the coachee's account). Only the first two are **first-hand**.                                                                                                |                                             |
| **Demonstration**                     | One credit: a skill shown at a level, by one observer, in one interaction, with its **role** and **points**. Append-only.                                                                                                                                                | Points, which are its value                 |
| **Role**                              | A skill's place in one piece of work: `primary` (what the work is mainly about; at most one) or `secondary`. Set on an activity and template; owned by the observer on an observation. Credit signed before roles existed is `unclassified` and never counts as primary. | Grant role                                  |
| **Points**                            | What one credit is worth: a whole number fixed at signing and never changed. A piece of work counts once per skill, at its highest value. Never redeemable, never compared across people.                                                                                | Demonstration, which is the credit itself   |
| **Points source**                     | Where a credit's points came from: `activity` (an individual value), `template` (the template's value copied onto the work), `skill`, `tenant`, or `legacy` (signed before points, worth 10).                                                                            |                                             |
| **Individual value**                  | A value for one skill on one piece of planned work, set by a plan agreer or a program owner, never the person whose work it is, inside the tenant's range, with a reason, before the work is observed; it applies only to work done from the day it is set.              | Template value                              |
| **Credit policy**                     | The tenant's versioned settings for points and badge criteria (`tenant.settings.creditPolicy`). The screen calls it "Credit rules". Read exactly as stored; changed only by a reasoned, audited save. Its numbers are working defaults until the firm's experts decide.  | Scoring policy version, which is the code's |
| **Reversal**                          | The record that cancels one demonstration, written when its observation is voided.                                                                                                                                                                                       | Deletion, which never happens               |
| **Badge**                             | Recognition that a level was shown in work worth enough points, in enough pieces of work, by enough observers, first-hand, over time. Levels 2 and 3 are awarded automatically.                                                                                          | Demonstration, plan target                  |
| **Acknowledge / request review**      | The subject's response to a signed observation.                                                                                                                                                                                                                          |                                             |

## Assistant and governance

| Term                | Meaning                                                                                                                                                | Not to be confused with |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------- |
| **Assistant check** | One Decisions API evaluation, recorded with digests, probabilities, thresholds, effect and rationale. It may hold, escalate or nudge. It never clears. |                         |
| **Question set**    | A versioned set of closed questions with thresholds, e.g. `privacy-screen` v1. Changing the wording bumps the version.                                 | Prompt                  |
| **Hold / escalate** | Hold: suspected client PII, so the text is hidden until revised or released. Escalate: a complaint or specific recommendation, routed to compliance.   |                         |
| **Disposition**     | A human's explicit decision on a check (agreed or overrode), recorded with who and why.                                                                | Audit event             |
| **Note**            | A human-written reason (return note, void reason, …). It is purgeable content, linked from the audit event.                                            | Audit event             |
| **Audit event**     | An immutable record of who did what, when, why (reason code and note) and under which policy version.                                                  | Activity                |

## Home and notifications

| Term               | Meaning                                                                                                                                                                                                                                                                                              | Not to be confused with    |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| **Waiting on you** | The first Home section: one queue of what needs the viewer, plus up to three people worth observing this week, each with a reason. Never a ranking.                                                                                                                                                  | Inbox ("To sign")          |
| **Notification**   | One outbox row telling one person by email that something waits on them. Carries names, a verb, counts, dates and a link, never content (ADR 0018).                                                                                                                                                  | Audit event                |
| **Digest**         | The Monday 07:30 email (tenant time zone) summarizing what waits, in counts and dates. Not sent when empty. No comparisons.                                                                                                                                                                          | Notification for one event |
| **Adoption view**  | The program owner's page of four aggregate numbers: people with a plan, observed recently, median days to sign, expiry rate. No names. A figure drawn from fewer than five people, or one that would let a reader work out a smaller group, is shown as "withheld". Voided observations never count. | Team view                  |

## What we say to users

Code and docs use the terms above. The UI uses plain words:

| Internal term                    | In the UI                                                                                                                                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Interaction                      | "work" ("Log work I did")                                                                                                                                                                              |
| Observation (quick capture)      | "I saw this"; its narrative is "What I saw". Work already logged that day is offered first                                                                                                             |
| Development plan                 | "My plan"                                                                                                                                                                                              |
| Coaching engagement              | coaching ("People I coach", "Stop coaching")                                                                                                                                                           |
| Demonstration                    | "times observed"                                                                                                                                                                                       |
| Role                             | "Primary" and "Secondary"; credit from before roles is "Observed before roles"                                                                                                                         |
| Points                           | "points" ("10 points")                                                                                                                                                                                 |
| Points source                    | On a plan: "set for this work", "from the template", "the skill's value", "the standard value". On a signed credit: "value set for this work", "value from the template" (the others are not labelled) |
| Feedback-only rating             | "Feedback only, adds nothing"; the sign screen says what signing adds ("Signing adds …")                                                                                                               |
| Individual value                 | "Set value"                                                                                                                                                                                            |
| Credit policy                    | "Credit rules"                                                                                                                                                                                         |
| Program catalog administration   | "Skill catalog" and "Activity templates" (the read-only catalog is "Skills")                                                                                                                           |
| Plan target                      | "Plan target"                                                                                                                                                                                          |
| Closing review                   | "Closing review"; outcomes "Achieved", "Partly", "Carried over to my next plan", "Not pursued"                                                                                                         |
| Badge receipt                    | "How this was earned"                                                                                                                                                                                  |
| Designation / designated basis   | "Asked to observe"                                                                                                                                                                                     |
| Assistant check (privacy screen) | "Automated privacy check"; the admin page is "Assistant checks"                                                                                                                                        |
| Inbox                            | "To sign"                                                                                                                                                                                              |
