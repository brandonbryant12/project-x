# Open questions for the product owner

Questions 1–19 are ranked by impact; 20 onward were added in the hub round.
Each open question has a **working default** so the build can continue. A
decided question records the date and where it was decided. Change a default by updating this file and the code together. If the
change reverses an architectural decision, add an ADR as well.
